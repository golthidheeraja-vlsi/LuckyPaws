## Website prototype

- **Rescue & Stray:** report a stray, injured or missing animal with a photo, area, city and PIN code.
- **My Pet:** pet profiles, health records and reminders.
- **Emergency Help:** first aid for seizures, poisoning, vomiting and breathing trouble; find vet clinics by PIN code and a sample list of 24/7 clinics; saved emergency contacts.
- **Food & Care** guide and **Ask LuckyPaws** for common questions.

Data is stored only in the browser (localStorage). Clinic names and numbers are sample data for the prototype.
Pet illustrations are free illustrations from [Unsplash](https://unsplash.com).

## Run the C program

```bash
gcc luckypaws.c -o luckypaws

```
